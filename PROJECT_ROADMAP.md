# Development Principles

Every sprint must include:

- Backend implementation
- UI/UX improvements
- Automated testing
- Documentation updates
- Defense notes (why this design was chosen)

Goal:
Build a production-style Clinical Decision Support System for a Philippine lying-in clinic, not just a school CRUD project.

Architecture priorities:

1. Small, focused services
2. Explainable clinical decisions
3. Incremental refactoring
4. Safe clinical workflow
5. Real-world usability for clinic staff
6. Maintainable codebase
