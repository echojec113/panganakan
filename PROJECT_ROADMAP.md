# Project Roadmap

## Sprint Standard

Every sprint must include:
- Backend implementation (services, extraction, refactoring)
- UI/UX consideration (document any frontend constraints)
- Focused tests covering the extracted behavior
- Documentation update (IMPLEMENTATION_PROGRESS.md)
- Defense notes explaining architectural decisions
